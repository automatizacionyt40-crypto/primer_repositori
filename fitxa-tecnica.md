# Fitxa tècnica: Instal·lació i configuració de Visual Studio Code

## Objectiu

L'objectiu és explicar la instal·lació i configuració bàsica de Visual Studio Code en un ordinador amb Windows.

## Materials

- Ordinador amb Windows
- Connexió a Internet
- Visual Studio Code
- Git

## Procediment

1. Descarregar Visual Studio Code.
2. Executar l'instal·lador.
3. Acceptar els termes de la llicència.
4. Seleccionar les opcions d'instal·lació.
5. Finalitzar la instal·lació.
6. Obrir Visual Studio Code.
7. Comprovar que funciona correctament.

## Comprovacions

- [ ] Visual Studio Code està instal·lat.
- [ ] El programa s'obre correctament.
- [ ] Es pot crear i editar un fitxer.
- [ ] El terminal integrat funciona.

## Incidències i solucions

| Incidència | Solució |
|---|---|
| El programa no s'obre | Reiniciar l'ordinador i tornar a obrir-lo. |
| No es pot crear un fitxer | Comprovar els permisos de la carpeta. |
| El terminal no funciona | Revisar la configuració del terminal. |
